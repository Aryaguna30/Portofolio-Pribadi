# Rencana Implementasi: Portfolio Website

## Overview

Implementasi website portofolio profesional berbasis Laravel 12 + Inertia.js + Vue.js 3 + Tailwind CSS.
Tampilan mengacu pada `preview/index.html` sebagai referensi visual yang harus direplikasi secara identik.
Animasi menggunakan GSAP, multi-bahasa via vue-i18n, dan admin panel sebagai CMS dinamis.
